# GrammarQuest — контекст проекта

Тренажёр казахской грамматики для русскоязычных школьников 12–17 лет.
Работает офлайн: сайт, устанавливаемое веб-приложение (PWA) и Android-приложение.

**Сайт:** https://grammarquest-web.vercel.app
**Репозиторий:** github.com/s-chaikovskiy/grammarquest-web

---

## Что это за продукт

Ученик проходит шаг урока по одной схеме: диалог с персонажем → грамматическое
правило → задание → разбор ответа. Задания возвращаются на повторение по
интервальному алгоритму. Весь материал двуязычный: казахский — целевой язык,
русский — объяснение и перевод.

Содержание: 18 уроков, 187 заданий, 33 правила, 22 темы справочника.

---

## Главное техническое решение

Девяти казахских букв **ә ғ қ ң ө ұ ү һ і** нет на русской раскладке, а они
встречаются в 168 из 187 правильных ответов. Поэтому:

1. Проверка ответов сводит казахские буквы к русским и засчитывает ответ,
   если верна грамматика, показывая при этом правильное написание.
2. Под полем ввода стоит экранный ряд этих девяти букв.
3. Шрифт приложения выбран по признаку полного покрытия этих букв.

Всё остальное в продукте построено вокруг этого решения.

## Команды

```bash
npm run dev        # разработка
npm test           # 31 автотест
npm run data       # пересобрать задания и проверить содержание
npm run build      # production-сборка
npm run icons      # пересобрать иконку и заставку
npm run android    # сборка + синхронизация проекта Android
python3 tools/contrast.py   # проверка контраста палитры
```

---

## Правила работы с содержанием

1. **Уроки правятся только в `lessons.source.json`.** Файл `lessons.json`
   собирается скриптом и перезаписывается — правки в нём пропадут.
2. **После правки содержания запустить `npm run data`.** Скрипт пересоберёт
   задания и проверит, что нигде не осталось объяснений про русскую грамматику.
3. **Изменение правильного ответа записывается в `tools/corrections.json`**
   вместе с обоснованием. Скрипт применения сверяет прежнее значение и
   останавливается, если оно не совпало.
4. **Палитру менять только вместе с прогоном `tools/contrast.py`.**

## Мобильная сборка

Android-приложение собирается в облаке через GitHub Actions: локальный
Android SDK не нужен. Папка `android/` не хранится в репозитории — она
целиком генерируется командой `npx cap add android` при каждой сборке.

Готовый файл появляется в артефактах сборки, а для тега вида `v1.0` —
в разделе Releases.
