готовые ответы на пять вопросов, которые жюри задаёт чаще всего.

## Что вписать перед защитой

Открыть `презентация/тексты.py`, верхний блок:

```python
AUTHOR = "Фамилия Имя"
GRADE_RU = "__ класс"
GRADE_KZ = "__ сынып"
SCHOOL_RU = "школа №__, г. ____"
SCHOOL_KZ = "№__ мектеп, ____ қаласы"
MENTOR_RU = "научный руководитель: ____"
MENTOR_KZ = "ғылыми жетекші: ____"
```

Данные попадут на титул и финал обеих версий сразу. После правки:

```bash
cd презентация && ./venv/bin/python build.py оба
```

```bash
cd презентация && soffice --headless --convert-to pdf "Тілашар-защита.pptx" "Тілашар-қорғау.pptx"
```

## Установка на телефон

**Android.** Chrome → меню «⋮» → «Установить приложение».
Либо файл APK из Releases — ссылка выше.

**iPhone.** APK не подходит: это файл только для Android. На айфоне путь один:

1. Открыть https://tilashar-kz.vercel.app **именно в Safari** — в Chrome
   на iPhone пункта установки нет, Apple его там не даёт.
2. Кнопка «Поделиться» — квадрат со стрелкой вверх, внизу экрана.
3. Пролистать список вниз → **«На экран „Домой"»**.
4. Имя предложит «Тілашар» — подтвердить «Добавить».

Значок появится на домашнем экране, приложение откроется без адресной
строки, как обычное. Интернет после первого открытия не нужен.

*Замечание честности: путь для iPhone логически выверен, но на живом
айфоне не проверялся. Если что-то пойдёт не так — скажите, что именно.*

## Как показывать приложение (5 минут)

1. **Открыть на телефоне** — навести камеру на QR со слайда 15.
2. **Главный экран** — дорожка уроков, видно пройденное и следующий шаг.
3. **Открыть первый урок.** Диалог → правило → задание.
4. **Главное место.** В задании с казахским словом набрать ответ
   **русскими буквами**: например «аке» вместо «әке». Приложение ответит
   **«Грамматика верна»**, засчитает и покажет правильное написание.
   Это и есть находка проекта — на этом стоит сделать паузу.
5. **Ряд казахских букв** под полем ввода: нажал — буква вставилась.
6. **Итоги урока** — разбор ошибок и повторный проход.
7. **Справка → Таблицы окончаний** — подставить любое своё слово
   и показать, что окончания считаются по правилам, а не берутся из списка.

Интернет для показа не нужен: после первого открытия приложение работает офлайн.

## Что честно сказать, если спросят

**«Результаты апробации есть?»**
Нет. Эксперимент запланирован, инструмент сбора встроен, данных пока нет.
Придумывать проценты не стали.

**«Уроки писал носитель языка?»**
Нет, и это касается всего текста. Восемь базовых уроков написаны в этой
работе, остальные восемнадцать сгенерировала прежняя программа, а потом
в них внесли 44 исправления. Правила и справочник — тоже машинный текст.
Носитель языка не видел ни одной строки, поэтому весь казахский текст,
167 690 знаков, выгружен учителю на проверку.

Так и говорить. Сказать «остальные взяты из прежней версии» — значит
намекнуть, что они проверены. Они не проверены.

**«Что здесь сделал ты, а что нейросеть?»**
Код помогала писать нейросеть. Работа исследователя — поставить вопрос,
измерить, найти причину и проверить результат. Прежняя версия как раз и была
написана без проверки — она не работала.

**«Озвучка есть?»**
Система готова: 589 фраз отобраны, у каждой свой голос. Записей пока нет —
нужен ключ синтеза или запись носителя языка.

## Что осталось незакрытым

1. **Проверка учителем — главное и самое объёмное.** Ни одна строка
   казахского в приложении не проверена носителем языка: ни новые уроки,
   ни исходные, ни правила со справочником. Всего **167 690 знаков**:

   - `НА-ПРОВЕРКУ-УЧИТЕЛЮ.md` — все 26 уроков, 93 905 знаков
   - `НА-ПРОВЕРКУ-СПРАВОЧНИК.md` — 33 правила и 22 темы, 73 785 знаков
   - `презентация/НА-ПРОВЕРКУ-КАЗАХСКИЙ-ТЕКСТ.md` — текст колоды, 164 строки

   Начинать с базового курса 5–7 класса — это первое, что видит пятиклассник.
2. **Титульные данные** — ФИО, класс, школа, руководитель.
3. **Озвучка** — нужен ключ Azure либо запись живого голоса.
4. **Апробация** — инструмент готов, данных нет.
5. **Персонажи и их происхождение.** Присланная картинка с героями так
   и не сохранена. Хуже: неизвестно, откуда взялись нынешние изображения —
   они достались от прежней версии без пометок. Если жюри спросит «откуда
   картинки», ответить нечего. Подробности — `assets-source/ОТКУДА-КАРТИНКИ.md`.
6. **Лицензия репозитория** — её нет. Репозиторий публичный, стоит выбрать
   (обычно MIT). Одна команда, но решение ваше.
