## Что вписать перед защитой

ФИО, класс и школа уже стоят: **Малышко Макар Евгеньевич, 6 «б» класс,
школа №35**. Осталось три поля — все в `презентация/тексты.py`, верхний блок:

```python
CITY = ""          # город, если нужен на титуле
MENTOR_RU = ""     # научный руководитель, если есть
MENTOR_KZ = ""
TEACHER_RU = ""    # ФИО учителя, проверившего казахский текст
TEACHER_KZ = ""
TESTERS = ""       # сколько одноклассников уже попробовало (число)
```

**Про два последних поля отдельно.** На слайде 08 стоит зелёная полоса
«тексты проверил учитель казахского языка · приложение попробовали
одноклассники». Жюри проверит это вопросом «кто именно?». Значит, к защите
это должно быть правдой: учитель действительно смотрит выгрузку, ссылку Макар
раздаёт одноклассникам. Живое число — «попробовали 12 одноклассников» —
убеждает сильнее общих слов.

После правки:

```bash
cd презентация && ./venv/bin/python build.py оба
```

```bash
cd презентация && soffice --headless --convert-to pdf "Тілашар-защита.pptx" "Тілашар-қорғау.pptx"
```

## Установка на телефон

**Android.** Chrome → меню «⋮» → «Установить приложение».
Либо файл APK из Releases — ссылка выше. APK работает офлайн сразу:
весь сайт лежит внутри пакета, сервер ему не нужен.

**iPhone.** APK не подходит: это файл только для Android. На айфоне путь один:

1. Открыть https://tilashar-kz.vercel.app **именно в Safari** — в Chrome
   на iPhone пункта установки нет, Apple его там не даёт.
2. Кнопка «Поделиться» — квадрат со стрелкой вверх, внизу экрана.
3. Пролистать список вниз → **«На экран „Домой"»**.
4. Имя предложит «Тілашар» — подтвердить «Добавить».

**Добавить на экран «Домой» на айфоне обязательно, а не желательно.**
Если оставить приложение просто вкладкой в Safari, iOS примерно через неделю
без открытия чистит хранилище сайта — вместе с сохранённым прогрессом ученика.
Значок на домашнем экране из-под этого правила выведен.

### Проверить офлайн — минута

1. Открыть, добавить на экран «Домой»
2. Позаниматься минуту, чтобы всё прогрузилось
3. **Включить авиарежим**
4. Открыть с экрана «Домой» — должно работать: уроки, словарь, справка

*Замечание честности: механизм проверен замерами, на живом телефоне —
ни на Android, ни на iPhone — ещё нет. Эта проверка и есть недостающий шаг.*

## Как показывать приложение (5 минут)

1. **Открыть на телефоне** — навести камеру на QR со слайда 07.
2. **Главный экран** — дорожка уроков, видно пройденное и следующий шаг.
3. **Открыть первый урок.** Диалог → правило → задание.
4. **Главное место.** В задании с казахским словом набрать ответ
   **русскими буквами**: например «аке» вместо «әке». Приложение ответит
   **«Грамматика верна»**, засчитает и покажет правильное написание.
   Это и есть находка проекта — на этом стоит сделать паузу.
5. **Ряд казахских букв** под полем ввода: нажал — буква вставилась.
6. **Итоги урока** — разбор ошибок и повторный проход.
7. **Справка → Таблицы окончаний** — подставить любое своё слово
   и показать, что окончания считаются по правилам, а не берутся из списка.

Интернет для показа не нужен: после первого открытия приложение работает офлайн.

## Что честно сказать, если спросят

**«Что здесь сделал ты, а что нейросеть?»**
Код помогала писать нейросеть. Работа автора — поставить задачу, проверить
результат и найти причину, если что-то не работает. Содержание уроков и все
решения — свои. Прежняя версия как раз и писалась без такой проверки, поэтому
половина задуманного в ней не работала.

**«Результаты апробации есть?»**
Одноклассники позанимались и сказали, что мешает. Настоящая апробация на классе
с цифрами — следующий шаг, сбор данных в приложение уже встроен. Проценты
не придумывали.

**«Кто проверял казахский текст?»**
Учитель казахского языка. Текст выгружается из приложения одним файлом — так
проверять удобно, и так же будут проверяться новые уроки.

*Пока проверка не состоялась, отвечать по-другому:* «Весь казахский текст,
167 690 знаков, выгружен учителю на проверку — это первый пункт плана развития».
Сказать «текст взят из прежней версии» нельзя: это намекает, что он проверен.
Он не проверен.

**«Озвучка есть?»**
Система готова: 589 фраз отобраны, у каждой свой голос. Записей пока нет —
нужен ключ синтеза или запись носителя языка.

**«Приложение платное?»**
Нет. Открывается по ссылке, работает без интернета, ставится на телефон.
Все сервисы, на которых оно сделано, тоже бесплатные.

## Что осталось незакрытым

1. **Проверка учителем — главное и самое объёмное.** Ни одна строка
   казахского в приложении не проверена носителем языка: ни новые уроки,
   ни исходные, ни правила со справочником. Всего **167 690 знаков**:

   - `НА-ПРОВЕРКУ-УЧИТЕЛЮ.md` — все 26 уроков, 93 905 знаков
   - `НА-ПРОВЕРКУ-СПРАВОЧНИК.md` — 33 правила и 22 темы, 73 785 знаков
   - `презентация/НА-ПРОВЕРКУ-КАЗАХСКИЙ-ТЕКСТ.md` — текст колоды, 76 строк

   Начинать с базового курса 5–7 класса — это первое, что видит пятиклассник.
2. **Строка «уже сделано» на слайде 08** должна стать правдой: проверка
   учителя и попробовавшие одноклассники.
3. **Проверка на живом телефоне** — Android и iPhone, порядок выше.
4. **Озвучка** — нужен ключ Azure либо запись живого голоса.
5. **Апробация** — инструмент готов, данных нет.
6. **Персонажи и их происхождение.** Присланная картинка с героями так
   и не сохранена. Хуже: неизвестно, откуда взялись нынешние изображения —
   они достались от прежней версии без пометок. Если жюри спросит «откуда
   картинки», ответить нечего. Подробности — `assets-source/ОТКУДА-КАРТИНКИ.md`.
7. **Лицензия репозитория** — её нет. Репозиторий публичный, стоит выбрать
   (обычно MIT). Одна команда, но решение ваше.
