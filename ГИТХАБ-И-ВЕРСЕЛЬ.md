# GitHub и Vercel — что это и зачем они в нашем проекте

Короткое объяснение для того, кто будет защищать проект. Прочитать один раз
перед выступлением: этот вопрос жюри задаёт часто, и на него легко ответить
уверенно, если понимать суть.

---

## Коротко

**GitHub** — место, где живёт исходный код и вся история его изменений.
**Vercel** — место, которое берёт код с GitHub и превращает его в работающий
сайт по адресу.

Первый хранит и проверяет. Второй показывает людям.

---

## GitHub — тетрадь, которая помнит всё

Представь тетрадь, в которой ты пишешь черновик проекта. Обычная тетрадь
помнит только последнее состояние: стёр — и прежнего нет. GitHub помнит
**каждое изменение с самого начала**.

### Что это даёт на практике

**Можно вернуться назад.** Сломал что-то вчера — открываешь версию
позавчерашнюю. В нашем проекте таких сохранённых состояний уже больше сорока,
и у каждого написано, что именно в нём поменялось и почему.

**Видно, кто и что сделал.** Для научного проекта это важно: жюри может
открыть репозиторий и увидеть, что работа велась постепенно, а не появилась
за одну ночь.

**Там же живёт автоматический проверяющий.** Он называется GitHub Actions.
Каждый раз, когда мы отправляем изменения, GitHub сам, без человека:

1. проверяет, что типы в коде сходятся;
2. прогоняет **70 автотестов** — например, что «кітап» + «ым» даёт «кітабым»;
3. собирает приложение;
4. собирает файл установки для Android.

Если хоть один тест упадёт — сборка покраснеет, и мы сразу об этом узнаем.
Это как если бы тетрадь сама подчёркивала ошибки красным.

**Адрес нашего репозитория:**
https://github.com/s-chaikovskiy/grammarquest-web

---

## Vercel — витрина, которая обновляется сама

Код на GitHub — это ещё не сайт. Это как чертёж дома: он есть, но жить в нём
нельзя. Чтобы приложение открылось в браузере, кто-то должен взять код,
собрать из него готовые файлы и положить на сервер, к которому есть доступ
из интернета.

Раньше это делали руками: собрал, скопировал файлы на сервер по одному.
Vercel делает это сам.

Он **следит за нашим репозиторием на GitHub**. Как только там появляется
новая версия — Vercel её замечает, собирает и выкладывает. Через минуту-две
сайт уже обновлён, и никто ничего не копировал.

**Адрес нашего сайта:**
https://tilashar-kz.vercel.app

---

## Как это работает у нас — цепочка целиком

| Шаг | Что происходит | Кто делает |
|---|---|---|
| 1 | Изменили код | человек |
| 2 | Отправили изменения | человек, одной командой |
| 3 | Проверка типов и 70 тестов | GitHub, сам |
| 4 | Сборка файла для Android | GitHub, сам |
| 5 | Сборка сайта | Vercel, сам |
| 6 | Сайт обновился по адресу | Vercel, сам |

**Человек делает только первые два шага.** Остальные четыре происходят
без него.

---

## Почему это важно именно для научного проекта

Три вещи, которые стоит сказать вслух.

**Работа проверяема.** Любой член жюри может открыть репозиторий и посмотреть
код, историю, тесты. Это не «поверьте на слово» — это можно проверить.

**Числа в докладе не выдуманы.** Все они считаются скриптами, которые лежат
там же в репозитории. Например, «193 из 225 ответов содержат буквы, которых
нет на русской раскладке» — это не оценка на глаз, это результат работы
программы, которую можно запустить заново.

**Ошибки не проходят молча.** Если завтра кто-то сломает правило про
озвончение — тесты упадут ещё до того, как приложение попадёт к ученикам.

## Что сказать, если спросят на защите

> «Код проекта лежит на GitHub — это сервис, где хранится исходный код и вся
> история изменений. Там же при каждом обновлении автоматически прогоняются
> 70 тестов и собирается файл для Android.
>
> Vercel следит за этим репозиторием и сам выкладывает новую версию сайта.
> От момента, когда я внёс правку, до момента, когда её видят ученики,
> проходит около минуты, и никто ничего не копирует руками.
>
> Мне это было нужно не для красоты: приложение можно проверить, а не только
> посмотреть. Весь код открыт, все числа в докладе считаются скриптами
> оттуда же.»

## Если спросят подробнее

**«Это платно?»**
Нет. И GitHub, и Vercel бесплатны для открытых проектов такого размера.

**«А если интернет пропадёт на защите?»**
Приложение работает без интернета. Он нужен только чтобы открыть его первый
раз — дальше всё лежит в телефоне.

**«Ты сам это настраивал?»**
Настройку автоматической проверки и сборки писали вместе с помощником, но
понимать, что она делает, обязательно: без этого нельзя объяснить, почему
проект можно проверить.

| Деплой | Выкладка новой версии сайта |
| APK | Файл установки приложения для Android |
