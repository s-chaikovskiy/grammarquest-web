# Документы к заявке на олимпиаду

Два документа для версии 2.0, собранные **по оглавлению прошлогодней защиты**:
те же разделы, та же нумерация, тот же порядок. Учителю не нужно сверять
структуру — достаточно прочитать содержание.

| Файл | Что это | Объём |
|---|---|---|
| **Тілашар – техникалық сипаттама.docx** | Техническое описание, 12 разделов | 15 страниц |
| **Тілашар – пайдаланушы нұсқаулығы.docx** | Руководство пользователя, 10 разделов, 11 скриншотов | 16 страниц |
| `*.pdf` | То же для чтения и печати | |

Оригиналы прошлогодних документов, по которым строилась структура, лежат
в `олимпиада/` — эта папка мимо git, там чужие файлы.

## Главное, что нужно знать про эти документы

**Казахский текст писал ассистент, а не носитель языка.** Как и весь остальной
казахский в проекте, он требует проверки учителем. Это первое, о чём надо
предупредить, передавая файлы.

**Раздел 1.4 технического описания — ключевой.** Он показывает, что версия 2.0
не новый проект, а выполненный пункт 11.5 прошлогоднего документа
(«PWA нұсқасы – веб-браузерде», «Android нұсқасы»). Там же таблица: что было
запланировано в разделе 11 версии 1.0 и что из этого сделано.

**Название.** В документах проект называется «Тілашар (Grammar Dialogue Quest
жобасының 2.0 нұсқасы)» — исходное имя проекта сохранено, чтобы бумаги сходились
с заявкой, а «Тілашар» подан как имя второй версии. Если учитель решит иначе,
правится в одном месте: `ЗАГОЛОВОК` и `ПОДЗАГОЛОВОК` в файлах текста.

## Как устроено

Текст лежит отдельно от вёрстки — так же, как в презентации:

| Файл | Что внутри |
|---|---|
| `техническое.py` | Весь текст технического описания |
| `руководство.py` | Весь текст руководства пользователя |
| `сборка.py` | Вёрстка: шрифты, поля, заголовки, таблицы, картинки |
| `скриншоты/` | 11 снимков экрана приложения |
| `скриншоты-экранов.mjs` | Снимает статические экраны |
| `скриншоты-урока.mjs` | Снимает урок по фазам: диалог → правило → задание → разбор |

Правка текста не требует правки оформления, и наоборот.

## Пересборка

```bash
cd документы && ../презентация/venv/bin/python сборка.py
```

```bash
cd документы && soffice --headless --convert-to pdf "Тілашар – техникалық сипаттама.docx" "Тілашар – пайдаланушы нұсқаулығы.docx"
```

## Пересъёмка скриншотов

Нужны, если менялись экраны. Сначала поднять Chrome с отладочным портом:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-shots about:blank &
```

```bash
cd документы && node скриншоты-экранов.mjs скриншоты && node скриншоты-урока.mjs скриншоты
```

Скрипты снимают с боевого сайта, поэтому изменения сначала должны попасть
в прод. Пустой низ у снимков обрезается отдельно — код обрезки в журнале
сессии за 2 сентября.
