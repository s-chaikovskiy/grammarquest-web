# Документы к заявке на олимпиаду

Два документа для версии 3.0, собранные **по оглавлению прошлогодней защиты**:
те же разделы, та же нумерация, тот же порядок. Учителю не нужно сверять
структуру — достаточно прочитать содержание.

| Файл | Что это | Объём |
|---|---|---|
| **Тілашар – техникалық сипаттама.docx** | Техническое описание, 12 разделов | 15 страниц |
| **Тілашар – пайдаланушы нұсқаулығы.docx** | Руководство пользователя, 10 разделов, 10 скриншотов | 18 страниц |
| **Тілашар – техническое описание.docx** | То же по-русски, блок в блок | 15 страниц |
| **Тілашар – руководство пользователя.docx** | То же по-русски | 18 страниц |
| `*.pdf` | То же для чтения и печати | |

Оригиналы прошлогодних документов, по которым строилась структура, лежат
в `олимпиада/` — эта папка мимо git, там чужие файлы.

## Главное, что нужно знать про эти документы

**Версия 3.0 — приложение по заданию учителя.** 13 сентября 2026 учитель
попросила оставить только грамматику: темы с её листка, в каждом задании
диалог → ереже → тапсырма, говорящие персонажи. Документы описывают именно
эту версию. Раздел 1.4 технического описания показывает путь 1.0 → 2.0 → 3.0.

**Казахский текст писал ассистент, а не носитель языка.** Кроме пяти заданий
учителя, перенесённых дословно. Весь остальной казахский требует проверки
учителем — это первое, о чём надо предупредить, передавая файлы.

**Название.** В документах проект называется «Тілашар (Grammar Dialogue Quest
жобасының 3.0 нұсқасы)» — исходное имя проекта сохранено, чтобы бумаги сходились
с заявкой. Правится в одном месте: `ЗАГОЛОВОК` и `ПОДЗАГОЛОВОК` в файлах текста.

## Как устроено

Текст лежит отдельно от вёрстки — так же, как в презентации:

| Файл | Что внутри |
|---|---|
| `техническое.py`, `техническое_ru.py` | Весь текст технического описания |
| `руководство.py`, `руководство_ru.py` | Весь текст руководства пользователя |
| `сборка.py` | Вёрстка: шрифты, поля, заголовки, таблицы, картинки, оглавление |
| `скриншоты/` | 10 снимков экрана приложения |
| `скриншоты.mjs` | Снимает все экраны с боевого сайта: тема по шагам, ответы, русский режим |

Правка текста не требует правки оформления, и наоборот.

## Пересборка

```bash
cd документы && ../презентация/venv/bin/python сборка.py
```

Сборка сама обращает документы в PDF, проставляет номера страниц
в оглавлении и прогоняет четыре проверки: совпадение казахской и русской
версий, числа и следы прежней версии, пустые страницы, полноту описания.

## Пересъёмка скриншотов

Нужны, если менялись экраны. Сначала поднять Chrome с отладочным портом:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-shots about:blank &
```

```bash
node документы/скриншоты.mjs документы/скриншоты
```

Скрипт снимает с боевого сайта, поэтому изменения сначала должны попасть
в прод. Каждый кадр проверяется на размер 800×1720, а нажатие, не нашедшее
кнопку, роняет съёмку — в документ не уйдёт снимок не того экрана.
