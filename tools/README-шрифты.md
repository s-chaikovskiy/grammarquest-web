# Проверка казахских букв в шрифте

Слайд 07 презентации утверждает, что прежние шрифты приложения не содержали
казахских букв. Утверждение проверяется одной командой — жюри вправе попросить
показать.

## Разовая подготовка

```bash
python3 -m venv tools/.venv && tools/.venv/bin/pip install fonttools brotli certifi
```

## Проверка

```bash
tools/.venv/bin/python tools/check_fonts.py --скачать
```

Без `--скачать` проверяются только шрифты проекта, без обращения к сети.

## Что показывает проверка на 26.08.2026

```
Шрифт приложения (Golos Text, четыре сабсета)
  Набор целиком: все девять букв доступны

Прежние шрифты — кириллические сабсеты с Google Fonts
  ✗ Manrope             нет: ә ғ қ ң ұ (5 из 9)
  ✗ Playfair Display    нет: ә ғ қ ң ө ү һ (7 из 9)
```

Кириллические сабсеты запрашиваются у самого Google Fonts: прямые ссылки на
файлы меняются от версии к версии, а искать казахские буквы в латинском наборе
бессмысленно — их там не должно быть по определению.
