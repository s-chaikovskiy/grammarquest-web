# Записи озвучки

Каталог пуст намеренно — сюда кладутся звуковые файлы.

Приложение работает и без них: кнопка «послушать» показывается только там,
где запись действительно есть. Пустая кнопка, которая ничего не делает,
хуже её отсутствия.

## Что озвучивается

589 фраз, 20 091 символ: слова словаря, правильные ответы и реплики диалогов
по одной. Грамматические объяснения не озвучиваются намеренно — на слух они
не воспринимаются, а длинные записи никто не дослушивает.

Имя файла — код фразы из `src/data/audio-index.json`, формат mp3.

## Путь первый: синтез Azure

У Azure два казахских нейроголоса. Женский читает слова, ответы и реплики
Айши, мужской — Диму и учителя: иначе двух собеседников в диалоге не
различить на слух.

```bash
export AZURE_SPEECH_KEY=ключ
export AZURE_SPEECH_REGION=westeurope
python3 tools/tts/synthesize.py
```

Ключ живёт только в переменной окружения: ни в чат, ни в репозиторий он
не попадает. Бесплатный тариф Speech даёт 500 000 символов в месяц —
нам нужно 20 091, то есть весь курс укладывается в бесплатный объём.

Скрипт пропускает уже записанные файлы, поэтому его можно прерывать
и запускать повторно.

## Путь второй: живой голос

Список фраз — `tools/tts/фразы-для-записи.md`. Он отсортирован от самого
нужного к менее важному, поэтому запись можно прервать в любой момент:
приложение озвучит то, что записано, остальное просто останется без звука.

Для защиты запись носителя языка сильнее платного синтеза.

## После добавления записей — обязательно

```bash
python3 tools/tts/build_manifest.py
```

Приложение узнаёт о записях из списка, который составляется этой командой,
а не спрашивает файлы по сети. Так экран с диалогом не делает ни одного
запроса, пока запись не понадобилась, и обещание «работает без интернета»
остаётся правдой. Обратная сторона: **положили файлы — прогоните команду,
иначе приложение о них не узнает.**

Та же команда входит в `npm run data`.
