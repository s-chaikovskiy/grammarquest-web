# Записи озвучки

Каталог намеренно пустой. Сюда кладутся файлы `<код>.mp3`, где код берётся
из `tools/tts/audio-manifest.json`.

Два способа наполнить:

**Живой голос** — `tools/tts/фразы-для-записи.md` содержит таблицу «имя файла →
текст → перевод». Порядок в ней от самого нужного к менее важному, поэтому
запись можно прервать в любой момент: приложение озвучит то, что успели,
а остальное просто останется без кнопки.

**Синтез Azure** — `tools/tts/synthesize.py`. Нужны переменные окружения
`AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION`.

Встроенный в браузер синтез не используется: казахских голосов в системах
нет, и вместо казахского получается текст, прочитанный чужим языком.
Проверено на этой машине — 157 голосов, ни одного казахского.
